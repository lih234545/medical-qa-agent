# 医疗问诊 AI Agent — 架构图（可贴入 PPT）

> 下面是 4 张 Mermaid 图，用途分别对应 PPT 的不同页面。
> **如何变成图片**：
> - 方法一：打开 https://mermaid.live ，粘贴代码块里的内容，右上角导出 PNG/SVG，贴进 PPT。
> - 方法二：PyCharm / VS Code 装 Mermaid 预览插件直接看。
> - 方法三：若用 Typora、语雀、飞书文档，粘贴即可自动渲染。

## 图 1 · 总体 RAG 流程（对应 Slide 5 技术架构）

```mermaid
flowchart TD
    A[用户提问] --> B[医疗问诊 Agent]
    B --> C[调用检索工具<br/>search_medical_knowledge]
    C --> D[FAISS 向量检索<br/>Top-K 相似文档]
    D --> E{相似度 >= 0.5 ?}
    E -- 有命中 --> F[把参考资料交给通义千问<br/>仅据此组织答案]
    E -- 全部过滤 --> G[返回“无结果”标记]
    F --> H[生成可溯源的专业回答]
    G --> I[输出固定拒答话术]
    H --> J[返回给用户]
    I --> J
```

## 图 2 · 三类异构数据处理（对应 Slide 7 难点一）

```mermaid
flowchart LR
    subgraph 原始数据
        A1[disease_encyclopedia.json<br/>结构化·疾病百科]
        A2[drug_manuals.md<br/>半结构化·药品说明书]
        A3[patient_faq.txt<br/>非结构化·医患问答]
    end

    A1 -->|每条疾病拼成文本| B[统一 Document<br/>正文 + metadata]
    A2 -->|按 ## 药品名切分| B
    A3 -->|按空行切分问答| B

    B --> C[通义千问 text-embedding-v2<br/>向量化]
    C --> D[(FAISS 向量库<br/>41 条文档)]
```

## 图 3 · 项目模块分层（对应 Slide 6 模块设计）

```mermaid
flowchart TD
    M[main.py<br/>统一入口 build/cli/web]
    subgraph 交互层
        CLI[cli.py<br/>命令行]
        WEB[web.py<br/>Gradio 网页]
    end
    subgraph 核心层
        AG[agent.py<br/>检索工具 + Agent + 规则]
    end
    subgraph 数据处理层
        KB[knowledge_base.py<br/>解析 + 建索引]
    end
    CFG[config.py<br/>配置：路径/模型/阈值/文案]

    M --> CLI
    M --> WEB
    CLI --> AG
    WEB --> AG
    AG --> KB
    AG -.读取配置.-> CFG
    KB -.读取配置.-> CFG
```

## 图 4 · Agent 决策逻辑（对应 Slide 9 规则固化）

```mermaid
flowchart TD
    A[收到医疗问题] --> B[强制调用检索工具]
    B --> C{工具返回内容}
    C -- 命中参考资料 --> D[仅依据资料回答<br/>禁止补充预训练知识]
    C -- 无结果标记 --> E[原样输出固定拒答话术<br/>绝不臆造]
    D --> F[附带来源提示<br/>并建议遵医嘱]
```
