> 全套约 13 页，控制在 10~15 分钟答辩时长。

## Slide 1 · 封面
- **标题**：基于 LangChain + FAISS + 通义千问的医疗问诊 AI Agent
- 副标题：本地知识库驱动的可信医疗问答助手
- 姓名 / 班级 / 学号 / 日期

---

## Slide 2 · 项目背景与目标
- 场景：用户用自然语言咨询疾病、药品、用药等健康问题
- 痛点：通用大模型会「一本正经地胡说」，医疗场景不可接受
- 目标：**只依据本地权威知识库作答，查不到就拒答**
- 交付：命令行 + Web 两种交互方式

---

## Slide 3 · 需求分析
- 本地知识库（`/data`）：疾病百科(JSON)、药品说明书(MD)、医患问答(TXT)
- 技术栈：LangChain + FAISS + 阿里百炼通义千问
- 三条核心 Agent 规则：
  1. 相似度阈值 0.5 过滤不相关结果
  2. 仅基于检索结果回答，不加入模型自身知识
  3. 无结果必须拒答（固定话术）

---

## Slide 4 · 什么是 RAG（检索增强生成）
- 一句话：**先检索、后生成** —— 让大模型「开卷考试」
- 对比：纯大模型（易幻觉） vs RAG（有据可依、可溯源）
- 本项目正是用 RAG 来保证医疗回答的可靠性

---

## Slide 5 · 技术架构图
- 配一张流程图：
```
用户问题 → Agent → 检索工具 → FAISS 相似度检索 → 阈值过滤(0.5)
      ├─ 命中：参考资料交给通义千问，仅据此作答
      └─ 未命中：返回“无结果” → 输出固定拒答话术
```
- 向量化：text-embedding-v2 ｜ 对话：qwen-plus（temperature=0）

---

## Slide 6 · 项目模块设计（分层解耦）
- `config.py`：配置层（路径 / 模型 / 阈值 / 文案）
- `knowledge_base.py`：数据处理层（解析 + 建索引）
- `agent.py`：核心层（检索工具 + Agent + 规则）
- `cli.py` / `web.py`：交互层（共用同一套 `ask()`）
- `main.py`：统一入口（build / cli / web）
- 亮点：**业务逻辑只有一份，界面只是「壳」**

---

## Slide 7 · 难点一：三类异构数据统一处理
- JSON（结构化）→ 每条疾病拼成自然语言文本
- Markdown（半结构化）→ 按 `## 药品名` 切分，每种药一条
- TXT（非结构化）→ 按空行切分每组问答
- 统一转成 LangChain `Document`（正文 + 来源 metadata）
- 结果：12 疾病 + 12 药品 + 17 问答 = **41 条文档入库**

---

## Slide 8 · 难点二：相似度阈值过滤
- 问题：FAISS 默认 L2 距离，数值范围不定，0.5 阈值无意义
- 方案：向量归一化后换算成余弦相似度 `相似度 = 1 - 距离/2`
- 效果：相似度落在 0~1，阈值 0.5 直观可解释
- 低于 0.5 的结果全部过滤 → 触发拒答

---

## Slide 9 · 难点三：把规则「焊死」进 Agent
- 用系统提示词固化三条规则
- 检索工具无结果时返回特殊标记 → Agent 原样输出拒答话术
- 关键：**禁止大模型用自身预训练知识补充/扩写**
- 采用 LangChain 1.x 新 API `create_agent`

# 附：现场演示脚本（照着念/操作）

> 建议先运行 `python main.py cli`，依次输入以下问题。

**① 用药安全（命中·问答）**
- 输入：`二甲双胍漏服了要补吃双倍吗？`
- 预期：明确回答**不能补双倍**，应跳过漏服、按时服下一次，并提示遵医嘱。

**② 疾病百科（命中·JSON）**
- 输入：`2型糖尿病有哪些典型症状？`
- 预期：列出多饮、多尿、多食、体重下降、视力模糊、伤口愈合缓慢等。

**③ 用药禁忌（命中·说明书+问答）**
- 输入：`孕妇头痛发烧可以吃布洛芬吗？`
- 预期：回答**孕妇禁用布洛芬**，建议及时就医。

**④ 用药时间（命中·问答）**
- 输入：`高血压患者氨氯地平什么时间吃最好？`
- 预期：回答**早晨起床后服用**，不受进食影响。

**⑤ 拒答演示（知识库外）——最重要**
- 输入：`今天北京天气怎么样？`
- 预期：原样输出固定拒答话术：
  > “抱歉，本地知识库中暂无关于该问题的相关数据，我无法为您提供专业解答。建议您咨询专业医师或查阅权威医疗资料。”

> 讲解提示：第⑤个演示最能体现项目价值——**AI 知道自己「不知道」，不会瞎编医疗建议**。
