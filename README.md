# 医疗问诊 AI Agent（实训项目）

基于 **LangChain + FAISS + 阿里百炼通义千问** 构建的本地知识库医疗问诊智能助手。
Agent 严格遵循「仅基于本地知识库回答、检索无结果则拒答」的安全规则，提供**命令行**与 **Gradio Web** 两种交互方式。

---

## 一、功能特性

- 🔎 **RAG 检索增强**：把本地医疗资料向量化存入 FAISS，问答时先检索再回答。
- 🧩 **三类数据统一处理**：结构化 JSON、半结构化 Markdown、非结构化 TXT 各用不同解析策略。
- 🛡️ **严格安全规则**：
  - 相似度阈值过滤（默认 0.5），低于阈值的检索结果视为不相关；
  - 只依据检索结果回答，不使用模型自身预训练知识补充；
  - 知识库无相关内容时，礼貌拒答，绝不臆造医疗建议。
- 💬 **双交互模式**：命令行 / 网页聊天界面共用同一套 Agent 逻辑。

当前版本已经完成知识库扩充，三类数据源合计 **41 条文档**：

## 四、环境准备

1. 使用 conda 的 `python-demo` 环境（Python 3.12）。
2. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```
3. 配置阿里百炼 API Key 到环境变量 `DASHSCOPE_API_KEY`（已配置可跳过）。

---

## 五、运行方式

```bash
# 1) 构建 / 重建向量索引（首次或数据更新后运行）
python main.py build

# 2) 命令行交互
python main.py cli
#   查看 Agent 中间推理过程：
python main.py cli --verbose

# 3) 启动 Gradio Web 界面（浏览器访问 http://127.0.0.1:7860）
python main.py web
```

## 七、关键技术说明

- **向量化模型**：通义千问 `text-embedding-v2`。
- **对话模型**：通义千问 `qwen-plus`（temperature=0，保证严谨稳定）。
- **相似度计算**：向量归一化后用 FAISS 计算，余弦相似度 = `1 - 距离/2`，统一用 0.5 阈值过滤。
- **Agent 框架**：LangChain 1.x 的 `create_agent`（基于 LangGraph 的工具调用型 Agent）。

> ⚠️ 本项目仅用于教学实训演示，不能替代专业医疗诊断，实际健康问题请咨询专业医师。
